## 📌 Featured Project

### 🫀 ECG Diagnostic Assistant Platform

AI-assisted platform for **ECG analysis and clinical report generation**, focused on supporting the detection of cardiac abnormalities such as **Atrial Fibrillation**.

The project combines signal/image analysis, deep learning models, backend services, and an intelligent reporting flow to provide a more complete diagnostic support tool.

#### Main Features

- ECG signal and image analysis
- CNN-based classification approach
- Atrial Fibrillation detection support
- Clinical report generation
- Backend integration with FastAPI
- Web interface for visualization and interaction
- Risk and metric interpretation for clinical support
